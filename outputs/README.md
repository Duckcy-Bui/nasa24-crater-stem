# Kết quả chạy

Mỗi lần chạy lưu trong `outputs/<run_id>/`: `params.json`, `craters.json`, `run.json` (mã commit, image_id, loại dữ liệu, thời gian tạo). Ảnh các bước và bảng đánh giá bổ sung sau. `scripts/check_contracts.py` tạo một bản lưu mẫu giả lập ở đây; đó không phải kết quả phát hiện hố.

Tiền xử lý (S1-08) lưu `outputs/s108_<image_id>_<thời gian>/` gồm `overview.png`, `steps/`, `params.json`, `metadata.json`, `run.json`, `result.npz`; xem [TIEN_XU_LY.md](../docs/TIEN_XU_LY.md).
